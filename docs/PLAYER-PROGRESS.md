# 播放进度与选择协调

播放页将进度持久化和剧集、播放源选择拆为独立模块。ArtPlayer/HLS 初始化、弹幕、下载、AI 与观影室控制仍由原有组件处理。

| 模块 | 职责 |
| --- | --- |
| `src/components/player/playback-progress.ts` | 捕获包含来源、影片、集数和播放位置的快照；按完整身份去重；串行执行保存；新媒体就绪前禁止混用旧播放器时间 |
| `src/components/player/usePlaybackProgress.ts` | 定时保存入口、页面隐藏、关闭和客户端导航卸载时的进度保存；使用最新回调并清理事件监听 |
| `src/components/player/playback-switch.ts` | 本地单集恢复、下一集过滤、换源详情准备、过期请求隔离、播放记录迁移及 URL 选择同步 |

## 行为约定

- 切集只读取目标集的本地进度，不等待全局记录或远端数据库。
- 同集换源优先保留请求时的播放位置，其次读取原来源的对应集记录，最后回退到本地单集进度。
- 新来源集数不足时回到第一集，只恢复第一集自己的进度。
- 新选择提交前保存原集本地检查点。采样通过选择版本、实际媒体绑定与加载事件恢复，不依赖通用加载状态；旧媒体迟到的可播放事件无法消费新集恢复值。连续换源使用计划恢复值。
- 换源详情和进度查询只允许最新请求提交界面；切集、观影室 URL 导航及卸载使旧请求失效。
- 已捕获的进度保存与已提交的换源迁移共享执行队列，按捕获、提交顺序持久化。网络等待不阻止本地检查点写入和界面更新。
- 同一秒数的不同影片、来源和集数分别保存。连续相同快照可以合并，向前播放后回退到旧位置仍会更新记录。
- 切集与换源同步 URL 中的 `episode`，保留观影室等其他参数，避免 URL 监听将选择恢复成旧集数。
- 自动下一集使用同一切集入口，手动选择后旧媒体的延迟自动切集任务失效。相同 URL 对应新选择时仍更新媒体绑定，可复用已就绪媒体。

本地检查点在关闭前同步写入。关闭页面时的远端请求仍受浏览器终止策略限制；数据库客户端已有的后台重试仍由存储层管理，这里不承诺跨设备事务一致性。


回归覆盖退出与隐藏保存、客户端导航、不同集数同秒进度、保存失败重试、快速切换旧详情与旧查询、切换窗口采样、同集迁移、越界恢复、URL 参数保留及保存/迁移顺序。播放器启动与插件加载继续使用原有测试。
