# 多视频源订阅

管理后台 → 配置文件 → 添加订阅。填写名称和 URL 后，点击“拉取全部”或某一项的“单独拉取”，检查结果，再点击“保存并应用”。

- 最多 20 个订阅，支持 Base58 编码的 JSON 和普通 JSON；忽略内容首尾空白。
- 每项可单独启用、设置自动更新、调整优先级，并显示上次成功更新时间和错误。
- 手动配置优先，其次按订阅顺序合并。相同 API 地址去重；相同标识对应不同 API 时自动分配不同标识。
- 已有视频源标识尽量按 API 地址保留，避免仅因订阅排序变化影响收藏关联。
- 拉取失败保留该订阅上次成功内容和成功时间，不阻止其他订阅更新。
- 停用或删除订阅后，在保存时移除它独有的配置源；其他订阅仍提供的源、手动添加的源和手动配置继续保留。
- “手动配置与合并预览”可编辑本地 JSON、导入文件并查看合并结果。订阅更新不会覆盖手动 JSON。
- 拉取是预览操作；添加、删除、排序、开关以及拉取结果都需“保存并应用”才会生效。

## 兼容与存储

旧 `ConfigSubscribtion` 单订阅自动迁移到 `ConfigSubscriptions` 列表，原配置作为该订阅的缓存。没有旧订阅时，原配置保留为手动配置。

`ConfigFileLocal` 保存手动配置，`ConfigFile` 保存合并后的有效配置；每个订阅的 `ConfigContent` 保存最后成功内容。空列表会持久化，重启不会恢复已经删除的旧订阅。

自动更新沿用项目原有 Cron 调度，仅更新已启用且勾选“自动更新”的订阅。并发拉取最多 4 个；订阅配置仅站长可修改，地址限 HTTP(S)，请求设有超时，每份配置/响应限制 256 KiB。订阅下载沿用项目原有网络请求方式，兼容本机网络代理；媒体播放代理的防护不变。

## 验证

```powershell
pnpm check
docker compose -f compose.local.yaml build
node scripts/smoke-subscriptions.cjs
docker compose -f compose.local.yaml up -d --wait
```

集成脚本创建临时 Docker 容器和独立 SQLite 数据库，验证旧配置迁移、真实订阅拉取、合并、保存、自动更新失败保留、删除及重启持久化；结束时移除测试容器，不使用本地运行容器的数据库。

2026-09-13 验证完成：87 项测试通过，生产 Docker 镜像构建成功；独立容器的迁移、真实订阅、自动更新失败保留和重启持久化全部通过。浏览器验证两个订阅拉取、合并和保存成功。本地服务已升级并保持健康，原有订阅和 28 个视频源保留。
