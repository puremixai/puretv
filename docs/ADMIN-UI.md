# 管理工作台布局更新

2026-09-13：将原有纵向折叠面板改为独立管理工作台，沿用已有接口和权限规则。

## 布局与操作

- 独立管理导航替代观影侧栏，按内容管理、账号与站点、媒体服务、扩展与系统分组。每次只展示一个配置栏目，所有业务面板按需加载。
- 工作台展示真实的视频源、订阅、直播配置数量，提供常用操作入口和可直接处理的配置提示。重置和重载移动到站长专用的“系统维护”。
- 导航支持中文、功能名称和相关关键词搜索，例如输入 TMDB 可找到站点设置；`Ctrl/⌘ K` 聚焦搜索。手机使用可搜索的抽屉导航，支持 Escape 关闭与焦点约束。
- 地址栏保留当前栏目，如 `/admin#videoSource`；刷新或收藏该地址可以直接返回栏目。
- 视频源列表增加名称 / Key / API 搜索和启用状态筛选。全选仅作用于当前结果，修改筛选会清空选择，避免误操作隐藏的源；表格操作列保持可见。
- 站点设置拆为“基础信息、影视数据、搜索与播放、访问统计”四组，切换分组保留输入，统一保存。为 34 个输入补充标签关联，并保留流式搜索的关闭值。
- 订阅操作栏在滚动时保持可见，站点设置使用底部保存栏。表单输入未保存时显示提示，切换栏目可选择继续编辑或放弃；站点设置与订阅还有各自的草稿保护。刷新/离站沿用浏览器保护，多个脏状态订阅者不会重复弹出链接确认。
- 支持浅色、深色和窄屏布局。大表格在自己的容器中滚动，手机输入字号和触控区域适当放大。
- 观影页面的主题切换和个人设置固定在左侧菜单底部，折叠时保留两个图标；个人菜单向上展开并限制高度，支持 Escape 关闭。管理面板的主题切换也移到导航底部。
