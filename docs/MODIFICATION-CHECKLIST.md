### 逐项结果

1. **Socket**：建立连接时校验签名及持久化会话，每次发包重新检查；设备 ID 不能被其他账号接管，旧连接断开不会删除重连设备。房间身份来自已验证账号，房主恢复同时校验账号与令牌；公开列表不返回密码、房主凭据。客户端刷新和撤销场景有回归测试。
2. **登录**：统一 v2 签名及 Cookie 写入；浏览器只读公开资料。已有 Cookie 解析 API 接入持久化身份入口，绕过用户缓存检查角色/封禁；刷新时用条件更新，避免撤销与最后使用时间更新竞争。密码升级覆盖 SQL 和 Redis 适配器，真实数据库验证使用 SQLite。
3. **代理**：通用媒体/CMS 代理需要授权；外部播放使用媒体专用令牌；Node 逐跳 DNS 绑定、凭据剥离、流式取消、播放列表大小/读取时间限制。统一处理变体、音轨、字幕、密钥、MAP/PART 等 URI，并保留上游编码参数。Edge 使用显式主机名单，能力差异见升级说明。
4. **执行权限**：服务端源脚本和自定义过滤代码默认关闭；站长权限与脚本开关同时生效。Cron 删除默认口令，使用 Bearer Header，保留显式旧配置兼容。
5. **Hooks / lint**：修复 Sidebar、MobileBottomNav、EmailSettingsPanel 的条件返回；测试反复切换路由/弹窗。其余错误采用实际代码修正或带说明的局部例外；第三方校验器仅保留原有 `@ts-nocheck` 的目录例外，没有全局关闭 ESLint。
6. **运行环境**：跨平台环境变量命令、明确数据库配置、受路径限制的 SQLite 重置、启动前加载环境文件；`ADMIN_USERNAME` 避免 Windows OS 变量冲突；开发/生产构建目录分离。Windows 直接运行项目服务，Linux/Docker 生成 standalone。
7. **拆分**：后台共享弹窗、按钮样式、加载状态及 Xiaoya / Telegram / Email / AI 四个配置组件移到 `src/components/admin`；后台页面从 19147 行减为 17152 行。播放页提取源类型判断模块，媒体播放列表重写独立为可测试模块。大型页面仍需后续渐进拆分。
8. **持续检查**：新增 Linux/Windows CI 类型、lint、测试与本地联调，Linux 构建及生产联调；提供环境示例与升级说明。README 按实际 LICENSE 标注，LICENSE 原文未修改。

### 限制

- 本地生产/开发联调均通过；2026-09-13 已追加本地 Docker 构建、启动和联调验证，详情见 [Docker 本地运行](DOCKER-LOCAL.md)。GitHub CI 尚未在远端运行，也未部署 Cloudflare、EdgeOne 或 Vercel。
- Postgres、Turso、Redis、OIDC、Telegram 等外部服务没有逐一连通验证；播放回归覆盖授权、代理传输和列表改写，不代表所有第三方视频源均可用。
