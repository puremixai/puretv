## 使用

- 更新后先刷新已有后台页面，再保存配置。旧页面缺少版本号会收到刷新提示。
- 编辑期间收到 409 时，保留自己的改动并重新载入最新配置，再决定如何应用，服务端不会自动覆盖别人的更改。
- 恢复入口只供站长使用；配置历史包含密钥，因此只返回版本和时间列表，快照不会下发给普通管理员。
- `LOG_LEVEL=debug|info|warn|error` 控制服务端新日志入口；客户端可在构建时设置 `NEXT_PUBLIC_LOG_LEVEL`。默认为 `warn`。
- 自动检查周期依赖已有 Cron。Docker 的小时调度已覆盖订阅最短 1 小时周期；其他部署需自行确保 Cron 正常触发。

## 已知边界

- 媒体探测属于抽检，不能保证整部内容都可解码或第三方源持续有效；需要特殊解析器、DRM 或定制鉴权的源可能无法通过自动探测。
- 源健康统计使用独立键值记录，同一进程按源合并重复检查；多实例统计不属于配置事务，其计数可能受同时检查影响。
- 历史是应用配置快照，不替代数据库备份；用户密码、会话、观看记录等独立数据不会随配置历史回滚。
- SQL CAS 的真实数据库验证覆盖 SQLite；PostgreSQL、远程 D1/Turso 和 Redis 系列实现通过类型/构建检查，尚未逐一连接远程服务验证。
- 前端大文件继续缩小，但播放业务仍然复杂；剩余 lint 告警需按功能域继续处理，详见验收指标。
