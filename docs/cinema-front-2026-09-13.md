# 前台电影感极简风

本次覆盖影视首页、分类、搜索、短剧、播放、直播、私人影库、求片、观影室，以及音乐、漫画、电子书、电视端和登录相关页面。管理页面保留现有布局、配色和交互。

## 页面与组件

- `CinematicScope` 在根布局按路由隔离前台样式，不修改管理页的全局主题偏好。阅读器不强制深色，继续使用自己的纸张和阅读设置。
- `PageLayout` 为影视页面统一全宽内容和半透明顶部分类导航：完整菜单位于站点标识左侧，外观切换和个人设置位于右侧；不再显示左下角浮动栏，手机保留底部导航。全屏播放移除导航占位。
- 首页保留沉浸式推荐、可选择的精选片单、横向海报和横版剧集。分类页增加大图精选区，复用已有分类数据和图片代理，不增加推荐接口请求；加载时保留相同高度，避免筛选栏跳动。
- 搜索页突出片名搜索入口，结果、来源、年份等筛选保持原有逻辑。播放页调整画面比例与选集区域，简化准备播放状态，修复网页全屏后缩窄窗口无法找到退出按钮的问题。
- `CinemaPortal` 将前台视觉上下文传入收藏、影片详情、个人设置等公共弹窗；管理页和阅读器弹窗保持原有主题。
- 音乐、漫画、书库保留自己的分区导航，采用统一中性色、半透明表面和控件。电视端保留遥控焦点，使用清楚的白色轮廓。
- 外观按钮在前台切换“深邃 / 柔和”两档深色背景，在管理页和阅读器继续使用原有主题切换。

## 验证

- 类型检查通过；相关组件与管理工作台回归共 3 套、14 项通过。
- 检查首页、分类、搜索及结果、收藏弹窗、管理页、书库、音乐、漫画、电视端的浏览器渲染；覆盖桌面、390px 手机及电视尺寸。
- 使用 MDN 公开示例视频验证真实解码与播放，960×540 视频播放至结束，无媒体错误；验证收起选集、进入网页全屏及窄屏退出后恢复导航。
- 管理页使用浅色主题时，不存在前台样式容器和 body 标记；自动测试覆盖管理子路由、前台切入管理页、阅读器和弹窗隔离。
- 最终 Docker 镜像和正式本地服务均通过 52 个无动态参数页面的 HTTP 检查：无失败，音乐入口正常重定向，4 个样式文件均正常加载。另检查 320px 窄屏布局与 1920px 电视端方向键焦点。
- 浏览器验证使用独立 PostgreSQL 副本、独立缓存前缀与临时账号。音乐和书库仅在副本中启用以检查页面；没有调用付费 AI 生成，没有改动正式功能开关。

外部视频、音乐、漫画和书源的可用性仍取决于服务自身。本次验证播放能力使用可访问的公开示例，书库与漫画检查的是页面框架与空状态，不代表未配置的书源或漫画服务已可使用。

## 本地运行

导航改动首次部署验证使用 `moontvplus:cinema-nav-all`。完整菜单、外观切换和个人设置全部移至顶部导航栏，左下角浮动栏已移除。验证了 1280px、768px 和 320px 下的布局、抽屉打开与 Escape 关闭、焦点恢复、外观切换和个人下拉菜单；首页及搜索页部署后 HTTP 检查通过，健康接口返回 200。更新前镜像保留为 `moontvplus:before-nav-all`，数据库与 Redis 数据沿用原有卷。
