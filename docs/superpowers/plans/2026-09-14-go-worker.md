# Go worker 首期实施计划

用户已确认：在新目录增加 Go 服务，首期接管服务端离线下载和 OpenList 扫描，其他 API 继续由 Node 处理，现有调用契约兼容。

## 边界

- 工作目录保持当前仓库，分支 `codex/go-worker`；服务位于 `services/go-worker`，独立 Go module、Dockerfile 和 opt-in Compose override。
- 默认不开启。Node 的现有 URL、方法、参数、响应及登录/角色/功能权限继续作为外部契约。Go 只监听内部执行接口，使用独立共享 token；公开健康端点不泄露配置。
- `OPENTV_GO_OFFLINE_DOWNLOADS=true` 时，已授权的 `/api/offline-download` 请求委派到 Go。下载任务沿用既有 `tasks.json` 和单集文件布局，以原子保存替代同步逐分片全量写；单实例独占执行，同一下载卷不能同时由 Node 与 Go 写入。现有本地媒体 URL 继续由 Node 读取共享卷。
- `OPENTV_GO_OPENLIST_SCAN=true` 时，Go 负责 OpenList 登录、分页列举多个根目录和有界并发；Node 保留 torrent/name/hybrid 名称解析、TMDB 匹配、配置迁移、任务进度、元数据写入和缓存失效。首期扫描执行是两端协作，不声称已重写整个影库。
- worker 失联时明确失败，不能在写请求后自动切回 Node，避免重复任务。关闭开关及重启应用可以切回原实现；不自动修改实际部署。

## 实施与验证

1. 建立标准库 Go 服务与有界出站 HTTP 客户端，验证 token、健康、配置、取消、重定向和网络边界。
2. TDD 实现离线任务管理、旧文件导入、HLS 解析/下载/重写、全局并发、原子持久化、删除取消和重启暂停。使用临时文件和本地 HTTP fixtures。
3. TDD 实现 OpenList 根目录扫描，覆盖分页、登录刷新、部分根失败、目录过滤、确定性顺序和请求取消。不迁移 JS 标题解析。
4. 在既有权限检查后加入 Node 委派，默认关闭；测试原模式无 worker 请求、未授权无法调用 worker、状态/响应契约和失败不回退。保留签名 query。
5. 增加独立 Docker/Compose、环境示例、运行/切换文档及 Go CI，现有 Compose 默认服务不依赖 Go。
6. 运行 Go 单测、race（可用工具链）、vet、构建；Node 定向与全量 check；临时容器/端口验证服务和两端协议。审查后交付，不提交、推送或更新日常实例。

## 完成与验证记录

- 首期模块、默认关闭的 Node 适配、独立 Docker/Compose、配置与回退文档以及 Linux/Windows CI 已实现。
- 独立审查修复了 CONNECT 多 IP 尝试、跨请求扫描并发、慢客户端阻塞、任务库容量不对称、删除中的持久化恢复和 BOM 兼容问题，相关回归均验证了先失败再通过。
- Windows / Go 1.25：`go test ./... -count=1 -timeout=120s`、`go vet ./...`、二进制构建通过。
- Linux / Go 1.27：Docker 测试阶段的 `go vet ./...` 与 `go test -race ./... -count=1 -timeout=120s` 通过，最终运行镜像构建通过。
- `pnpm check`：79 个测试套件、1,275 项测试通过；14 项原有跳过，另有 4 项需要显式测试二进制的联调在普通检查中跳过。ESLint 为 0 错误，848 条存量警告，未提高基线。
- 设置测试二进制后，3 个套件、19 项桥接/扫描/真实进程联调全部通过，包括原下载及本地播放 API、签名 HLS、重试/删除、OpenList 列举和仅扫描进程不打开下载卷。
- `pnpm build` 通过，保留现有 middleware/Edge Runtime/Browserslist 警告。Go 格式检查、`git diff --check`、不加载实际环境文件内容的 Compose 配置校验通过。
- 隔离 Docker 运行验证：UID 1001、只读根文件系统、临时下载文件系统，内置 `--healthcheck` 成功，认证后的下载 API 返回空任务列表，停止后退出码 0。测试容器已移除。
- 实现与验证在 `codex/go-worker` 分支完成，验证过程未切换现有部署、真实环境文件或用户数据。
