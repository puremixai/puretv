# Go worker 后续迁移

用户已授权按建议迁移高、低优先级模块。沿用当前目录和 codex/go-worker 分支；不自动提交、推送或切换实际部署。

## 约束

- 公开 API 地址、权限判断和响应契约保持兼容；每个模块显式开启，默认使用 Node。
- Go 是内部执行服务，共享服务 token 不传浏览器。启用后失败明确返回，不自动重复执行 Node 写任务。
- 普通视频/IPTV 继续浏览器直连。文件经 Next 转发仍经过 Node，不将其描述为带宽卸载。
- 配置、用户权限、多后端数据库、动态 JS 源和 Socket.IO 保留 Node。后台执行可协作，任务提交必须避免双执行。
- 测试使用临时目录和本地上游，不读取或修改实际环境及用户数据。

## 任务

1. 本地下载文件：Go 安全文件流、Range/HEAD、清单 URL 兼容；Node 两入口适配和授权测试。
2. 直播预检/EPG：有界 HTTP、解压与解析、取消；保留频道时区映射与 Node fallback。
3. 网盘检查：原平台协议、可取消和持久任务、现有 start/task/cancel 契约。
4. OpenList：延伸文件操作/扫描执行与持久进度查询，保留名称解析、匹配和最终 DB 提交在 Node。
5. 搜索：指定源标准 CMS 执行优先，再接入综合搜索的标准源；保留 JS 源、SSE 和权限/排序。
6. 后台任务：配置订阅拉取及追番外部执行委派，可靠任务租约/去重，Node 保留配置及通知提交。
7. 弹幕与元数据：原生有界弹幕读取/解析、TMDB/Bangumi 外部 JSON 请求；保留缓存、密钥轮换与原接口。
8. 集成：配置、Compose、文档；Go test/vet/race、Node check、真实进程联调和构建；独立审查修复。
